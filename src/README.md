# موقع «نَفَس»

موقع تعريفي بمشروع «نَفَس» في دمشق، جاهز للنشر كما هو.

## الصفحات

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `cooks.html` | للطاهيات، مع نموذج طلب الانضمام |
| `tasters.html` | أول الذوّاقة، مع نموذج التسجيل |
| `about.html` | من نحن، ومصادر الصور |
| `privacy.html` | سياسة الخصوصية |
| `terms.html` | شروط الاستخدام |
| `404.html` | صفحة الخطأ |

## النشر على Netlify (أسرع طريقة)

1. فكّ ضغط الملف.
2. افتح https://app.netlify.com/drop وسجّل الدخول.
3. اسحب **المجلد** كاملاً (لا الملف المضغوط) إلى الصفحة.
4. بعد دقيقة يظهر رابط الموقع. يمكن تغيير اسمه من Site configuration ← Change site name.

لتحديث الموقع لاحقاً: من صفحة الموقع على Netlify ← Deploys ← اسحب المجلد الجديد.

## بعد النشر

- **صورة المشاركة:** وسم `og:image` يحتاج رابطاً كاملاً حتى تظهر الصورة عند مشاركة الرابط على واتساب وفيسبوك. أرسل رابط الموقع ليُعاد البناء به.
- **رقم واتساب:** الرقم الحالي `+963 962 934 928`. يُقرأ من الوسم `<meta name="nafas-whatsapp">` في كل صفحة ومن روابط `wa.me`.
- **النماذج:** انظر القسم التالي.

## النماذج (Netlify Forms)

كل تسجيل يُحفظ لدى Netlify، ثم يجهّز الموقع رسالة واتساب يرسلها الزائر بنفسه. بهذا لا يضيع تسجيل لم يُرسل صاحبه الرسالة.

1. من صفحة الموقع على Netlify: **Forms ← Enable form detection** (مرة واحدة).
2. أعد نشر الموقع بعدها؛ الكشف عن النماذج يبدأ من النشر التالي.
3. تظهر في Forms النموذجان `cooks` و`tasters`، وتحت كل منهما التسجيلات.
4. للإشعار بالبريد عند كل تسجيل: **Forms ← Submission notifications**. تصل الرسائل من `formresponses@netlify.com`.

حقل `from` في كل تسجيل يقول من أين جاء الزائر: الرمز الموجود في الرابط (`?from=fb-mezzeh`)، أو اسم الموقع الذي أحاله، أو `direct`. الحقل `bot-field` فخّ للبرامج الآلية، ويبقى فارغاً عند البشر.

خارج Netlify (أي استضافة أخرى) يفشل الحفظ بصمت، وتبقى رسالة واتساب تعمل كما هي.
